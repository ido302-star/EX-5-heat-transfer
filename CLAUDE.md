# Project instructions

This is a Python assignment for a Mechatronics programming course, built in stages.

- After finishing each main stage of the assignment, run the code, verify it works,
  and make a git commit with a clear English message
  (e.g. "Stage 1: Body class with add_heat").
- Keep the code simple and readable, at an intro-course level, with short comments.
- Do not modify files from previous stages without asking the user first.
